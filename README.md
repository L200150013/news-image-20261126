# news-image-20261126 — The World in One Day

[![make.fun](https://img.shields.io/badge/make.fun-news--image--20261126-blue)](https://make.fun/c/news-image-20261126)

One image summing up the world's news of **Thursday 26 November 2026**:
the 100th Macy's Thanksgiving Parade postponed for the first time ever,
the NFL Thanksgiving tripleheader, World Chess Championship Game 3,
the 25th National Dog Show, 35 European football ties in one night,
and 30 verified stories from every region — with a DATE CHECK band
calling out the 25 November stories that are *not* today's news.

- `entry.png` — the image (1024×1024, drawn locally with PIL)
- `main.py` — standard library only; copies `entry.png` to `/output/entry.png`
  (or `$MAKEFUN_OUTPUT_DIR/entry.png`)

Every story in the image is dated Thursday 26 November 2026.
Pictures drawn for this page — no photographs.
